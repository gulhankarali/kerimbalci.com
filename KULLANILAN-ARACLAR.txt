KULLANILAN ARACLAR VE DOSYALAR
==============================

ARACLAR
-------
uv (v0.13.7)
    Python paket ve proje yoneticisi. Python surumunu, sanal ortami (.venv)
    ve tum bagimliliklari tek basina yonetir. pip + virtualenv + pyenv
    araclarinin hepsinin yerini alir ve cok daha hizlidir.
    Ornek komutlar: uv add <paket>, uv run pytest, uv sync

Python 3.11
    Projenin calistigi dil surumu. .python-version dosyasinda tanimlidir;
    uv bu dosyaya bakarak dogru surumu kullanir.

pytest (v9.2)
    Test framework'u. tests/ klasorundeki testleri calistirir.
    Calistirmak icin: uv run pytest

python-dotenv (v1.2)
    .env dosyasindaki ortam degiskenlerini programa yukler. Boylece ayarlar
    koda gomulmez (hardcoding yok), ortamdan okunur.

git
    Surum kontrol sistemi. Kod degisikliklerinin gecmisini tutar.
    uv init komutu depoyu otomatik olusturdu; .gitignore ile gizli ve
    gecici dosyalar (ornegin .env ve .venv) takip disi birakildi.

DOSYALAR VE KLASORLER
---------------------
pyproject.toml
    Projenin kimlik karti: adi, surumu, bagimliliklari ve pytest ayarlari
    burada tanimlidir.

uv.lock
    Tum bagimliliklarin tam surumlerini sabitler. Baska bir makinede
    "uv sync" calistirildiginda birebir ayni ortam kurulur.

.python-version
    Projenin kullandigi Python surumunu belirtir (3.11).

src/kerimbalci_com/
    Uygulama kodu (src layout). Icindekiler:
    - __init__.py : main() giris fonksiyonu
    - __main__.py : "python -m kerimbalci_com" ile calistirma noktasi
    - config.py   : tum ayarlari ortam degiskenlerinden okuyan modul

tests/
    pytest testleri. test_config.py ayar sisteminin dogru calistigini
    dogrular.

.env
    Gercek ortam degiskenleri (DEBUG, LOG_LEVEL vb.). GIZLIDIR,
    git'e commit EDILMEZ.

.env.example
    .env dosyasinin sablonu. Gizli bilgi icermez, git'e commit edilir.
    Yeni kurulumda: cp .env.example .env

.gitignore
    Git'in takip etmeyecegi dosyalar: .env, .venv, __pycache__,
    .pytest_cache vb.

.vscode/launch.json
    VS Code debug yapilandirmalari: uygulamayi, acik dosyayi veya
    testleri F5 ile adim adim debug etme.

.vscode/settings.json
    VS Code proje ayarlari: dogru Python yorumlayicisi (.venv),
    pytest entegrasyonu ve .env dosyasinin otomatik yuklenmesi.

INSTRUCTIONS.md
    Projenin kurallari ve calisma prensipleri (dinamiklik, hardcoding
    yasagi, debug kullanimi vb.).

SIK KULLANILAN KOMUTLAR
-----------------------
uv sync                      Bagimliliklari kur / ortami esitle
uv run pytest                Testleri calistir
uv run python -m kerimbalci_com   Uygulamayi calistir
uv add <paket>               Yeni bagimlilik ekle
uv add --dev <paket>         Gelistirme bagimliligi ekle
