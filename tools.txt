TOOLS AND FILES IN USE
======================
(Detailed documentation: the instructions/ folder)

TOOLS
-----
uv (v0.13)
    Python package and project manager. Manages the Python version, the virtual
    environment (.venv) and all dependencies. Replaces pip + virtualenv + pyenv.
    Examples: uv add <package>, uv run pytest, uv sync

Python 3.11
    Defined in .python-version; uv uses this version.

pytest (v9.2)
    Test framework. Folders: tests/unit, tests/integration, tests/<suite>.
    Markers: integration (needs network), eval (paid judge model).

python-dotenv (v1.2)
    Loads the .env file; settings are not hardcoded (config.py -> Settings).

deepeval (v4.3)
    LLM eval framework. Scores chatbot answers with the GEval metric and a
    judge model (JUDGE_MODEL). Integrates with pytest.
    Usage: uv run deepeval test run tests/factuality/

Confident AI
    deepeval's cloud platform (app.confident-ai.com). Tracks test runs and
    scores. Connected with CONFIDENT_API_KEY (.env).

anthropic (v2.7)
    API client for the judge model (Claude); used by deepeval's AnthropicModel.

gradio-client (v2.7)
    Connects to the chatbot (Gradio) on the Hugging Face Space (chatbot.py).

pyyaml (v6.0)
    Reads the judge YAML files under judges/.

git / GitHub
    Version control. .env, .venv, .cache, reports, .deepeval are not tracked.

FILES AND FOLDERS
-----------------
pyproject.toml / uv.lock   Project definition, dependencies, pytest settings / pinned versions
.env / .env.example        Real settings (SECRET, never committed) / template (committed)
CLAUDE.md                  Core project rules (Claude Code reads it every session)
README.md                  Project overview and quick start
instructions/              Documentation (setup, configuration, testing, debugging, deepeval, git)
dataset/factuality/        Factuality questions and expected answers (JSON, with evidence)
dataset/hallucination/     Hallucination trap questions (JSON, with evidence)
judges/factuality_judge/   Factuality judge definitions (YAML, level 1-3)
judges/hallucination_judge/ Hallucination judge definitions (YAML, level 1-3)
src/kerimbalci_com/
    config.py              Settings: all settings from the environment
    chatbot.py             ChatbotClient: sends questions to the HF Space
    datasets.py            Dataset loading and schema validation
    dataset_builder/       Dataset generation from the site (crawl, split, merge, verify)
    evals/                 Suites, parallel runner, judges (judge_config), reporter, CLI
tests/
    conftest.py            Shared fixtures (settings, chatbot, judge_model)
    unit/                  Tests without network
    integration/           Connection tests
    factuality/            Factuality eval test (paid)
    hallucination/         Hallucination eval test (paid)
.vscode/                   F5 debug configurations and project settings

COMMON COMMANDS
---------------
uv sync                                               Set up / sync the environment
uv run pytest -m "not integration"                    Fast unit tests
uv run pytest -m "integration and not eval"           Connection tests
uv run deepeval test run tests/factuality/            Factuality eval (Confident AI)
uv run deepeval test run tests/hallucination/         Hallucination eval (Confident AI)
uv run python -m kerimbalci_com.evals factuality      Parallel eval + reports/*.json
uv run python -m kerimbalci_com.dataset_builder crawl Crawl the site (dataset generation)
uv add <package> / uv add --dev <package>             Add a dependency
